Module 4: Audit report & checklist

Test-method guide

Keyboard-only

Unplug the mouse. Tab/Shift+Tab through everything: is focus visible, logical, never trapped? Do Enter, Space, arrows and Esc work as expected?

Screen readers

NVDA with Firefox or Chrome (Windows), VoiceOver with Safari (macOS/iOS), TalkBack (Android). Check names, roles, states, headings, landmarks and announcements of dynamic changes.

Zoom and magnification

Zoom the browser to 200% and 400% (320 CSS px), check no clipped content or sideways scrolling; apply text-spacing overrides; try the OS magnifier.

Contrast tools

Color pickers and contrast checkers (e.g. browser DevTools, Colour Contrast Analyser) for text, borders and icons; also check hover, focus and disabled-adjacent states.

Automated tools

axe DevTools, Lighthouse and WAVE are quick starting points. Automated tools detect only a portion of WCAG issues (commonly estimated at roughly a third); manual and assistive-technology testing is required.

Selected WCAG 2.1 A/AA checklist

This checklist covers selected criteria, not every WCAG requirement. A report records your tests; it is not a certification.
